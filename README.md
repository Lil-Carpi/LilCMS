# LilCMS

## Welcome to LilCMS, a lightweight, fast and reliable CMS made from scratch!
LilCMS is a personal project written in PHP. I will have a version on node.js
as soon as I finish this one.

### Status
**Phase 1: Core foundations**
- [ ] File structure and autoloader
- [ ] Config manager (config.php with environment loader)
- [ ] Basic routing system (GET/POST handler)
- [ ] Error handler & logger
- [ ] Template engine (simple include-based system)
- [ ] Basic response systems (headers, JSON, HTML output)
