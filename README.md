# LilCMS

## Welcome to **LilCMS**, a lightweight, fast and reliable CMS made from scratch!
LilCMS is a personal project written in **PHP**.
A Node.js version will come later once this one is done - same logic, new tech stack
btw, the Node version will be primary when I finish it...

### Status

**Phase 1: Core foundations**

- [ ] File structure and autoloader
- [ ] Config manager (config.php with environment loader)
- [ ] Basic routing system (GET/POST handler)
- [ ] Error handler & logger
- [ ] Template engine (simple include-based system)
- [ ] Basic response systems (headers, JSON, HTML output)

Stay tunned... Lmao

## Development Roadmap

### Phase 1 - Core foundations *(In progress)*
> Build the base structure and make it stable before adding any fancy feature.


### Phase 2 - Database & Authentication
- Database connection layer (MariaDB)
- Simple ORM/Query builder (custom made, obviously ツ)
- User system (login, roles, sessions, permissions)
- Password hashing & security checks

### Phase 3 - Admin Panel
- Dasboard layout (HTML + PHP templating)
- Content management (pages, posts, media)
- File uploads and media library
- Role-Based access control

### Phase 4 - API & Extensions
- Rest API endpoints for CRUD
- Plugin/extension system
- Custom fields and hooks
- Documentation site + CLI tool

### Phase 5 - Polish & Node Port
- Full testing & optimization
- Convert core logic to Node.js version
- Benchmark both versions
- Release LilCMS v1.0
