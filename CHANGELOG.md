# LilCMS (Atomic Ant) Version 0.1.0 - Initial Release

**Note about the versions**:
  Versions goes like this:
      `[Major update].[Status].[Minor update]`
- **Major update**: Represents a big update, with a lot of changes.
- **Status**: Represents the current major development phase of the project.
- **Minor update**: Represents the specific update or patch numbrer within that phase.
*Example: Major update 0, Status 2, update number 7: Version 0.2.7.*
